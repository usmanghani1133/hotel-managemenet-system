# HotelFlow Frontend

This directory contains the core React 19 + Vite 8 frontend application for the **Hotel Management System**.

Please refer to the main repository [README.md](../README.md) for full project documentation, architectural overview, and feature breakdown.

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Run Oxlint
npm run lint
```
